This project was completed for the University of Birmingham Year 1 Object Oriented Programming module. The task was to create a simple [Zork](https://en.wikipedia.org/wiki/Zork)-style game in Java, with the aim of demonstrating the ability to follow project specifications and apply object oriented programming principles.

The game is text-based and runs in the console. Players move from room to room, interact with objects, and solve puzzles in order to complete the game.
